# Maps

Maps is the ryOS **Apple MapKit JS** app for place search, pins, saved locations (Home / Work / Favorites), a Taiwan **YouBike** station overlay, and in-map **Drive**, **Transit**, and **YouBike** directions.

## Overview

Maps embeds Apple’s MapKit web stack inside a desktop window: search and geocoding run through MapKit, results and saved places appear as annotations, and the place card surfaces actions for each pin. **Drive** and **Transit** plan a route in-window with MapKit JS Directions (`Automobile` / `Transit`), draw a polyline, and show a route card that matches the YouBike trip card (summary, Steps, Start / Stop Navigation). If MapKit JS cannot return a route, the app falls back to Apple’s Maps Server API `/v1/directions`. **YouBike** stays the Taiwan-only walk → bike → walk planner. The place and route **More** menus open the current place or origin→destination in **Apple Maps** or **Google Maps**.

When Ryo uses the **`mapsSearchPlaces`** chat tool, the inline result list opens the chosen place **in ryOS Maps** (same window) so you can explore without leaving Chats; a separate control still opens **Apple Maps** in a new tab when you want the native client.

## Features

- **Place search** via MapKit (city, business, address)
- **Drop pins** from search results; recenter and zoom
- **Locate Me** to recenter on the current position (browser geolocation)
- **Saved places**: Home, Work, and Favorites with branded or category markers
- **Map types** (View menu): Standard, Hybrid, Satellite, Muted Standard
- **YouBike overlay**: live YouBike 2.0 stations in the current Taiwan viewport (View → YouBike); small full-opacity gradient dots with no labels. Light mode uses a white outer outline; dark mode uses brighter fills and a dark outline. Tap hides that dot and shows a MapKit POI labeled bikes/total (e.g. `4/60`); other docks stay. During directions, only start and end docks stay full size and opacity. Hidden at city-scale zoom (Taipei default and wider)
- **YouBike directions**: in-map walk / bike / walk legs; bike geometry prefers MapKit Cycling, then OSRM bike; camera fits the route; route card replaces the place card and keeps turn-by-turn street steps hidden until Steps is tapped. The step list fades when it scrolls, and tapping a step moves the map to that turn. With Locate Me on, passed steps dim and the step you are on stays highlighted.
- **Drive and Transit directions**: in-map automobile and transit routes via MapKit JS (Maps Server API fallback); route card with Drive / Transit tabs, step list, and Start Navigation
- **Open in Apple Maps / Google Maps**: place and directions More menus
- **Chats integration**: `mapsSearchPlaces` rows open places in-app; external link opens in Apple Maps

## User Guide

### Getting Started

Open Maps from the desktop or launcher. The default camera is Taipei (city scale) unless a selected place, granted location, or saved Home already frames the map. Type a query in the search bar, pick a result to drop a pin, and use the place card for details.

### Key Actions

- **Search**: Enter a place name or address; choose a result to focus the map and show the place card. **Drive**, **Transit**, and (in Taiwan) **YouBike** stay on the card. The round **More** button follows those buttons and opens Favorite, Set as Home, Set as Work, Open in Apple Maps, and Open in Google Maps.
- **Directions**: From the place card, **Drive** or **Transit** plans an in-map route (MapKit JS, then Apple Maps Server API if needed). The route card replaces the place card and shows time and distance. Use the Drive / Transit tabs to switch modes. **Steps** opens turn-by-turn directions. **Start Navigation** uses the same speech and Locate Me follow pattern as YouBike. In Taiwan, **YouBike** still plans walk → bike → walk legs. The More menu opens the current origin→destination in Apple Maps or Google Maps.
- **YouBike overlay**: Leave **View → YouBike** on (default). Stations appear only when the Taiwan viewport is zoomed in past city scale (plus a small pan margin). Browse-mode pins are small, fully opaque gradient dots. Light mode uses a white outer outline; dark mode uses brighter fills and a dark outline. Tap one to hide that dot, open the place card, and drop a MapKit POI whose label is bikes/total docks (e.g. `4/60`). The other docks stay on the map. During YouBike directions, docks that are not the start or end shrink and dim; start and end stay full size and opacity. They stay hidden outside Taiwan and at city-wide cameras.
- **Locate Me**: Use the toolbar control to recenter on your location (grant permission if the browser prompts).
- **Saved places**: Set Home and Work from the places drawer; star favorites to keep them on the map.
- **Map style**: Use the **View** menu to switch map type.

### Tips

- Drive and Transit need a start point: Locate Me, saved Home or Work, or a map center that is not the destination pin. Use **More → Open in Apple Maps** when you want the native client.
- From Chats, tapping a `mapsSearchPlaces` result launches Maps with that place selected — use the small external-link control if you prefer Apple Maps in a separate tab.

## Technical Details

### Requirements

MapKit JS needs a **MapKit origin** and credentials configured server-side (see project env docs for `MAPKIT_*` variables). Search and tiles depend on that setup.

### Component Architecture

- `src/apps/maps/components/MapsAppComponent.tsx` — Map instance, search, annotations, place card
- `src/apps/maps/components/MapsMenuBar.tsx` — Menus and map type switching
- `src/apps/maps/components/MapsPlaceCard.tsx` — Place details, **Drive** / **Transit** / YouBike, More menu
- `src/apps/maps/components/MapsDirectionsRouteCard.tsx` — In-map Drive / Transit trip card
- `src/apps/maps/components/MapsPlacesDrawer.tsx` — Home / Work / Favorites UI
- `src/apps/maps/directions/` — origin picker, MapKit / Server route parse, Apple and Google Maps URLs
- `GET /api/maps/directions` — Apple Maps Server API directions fallback (Automobile / Transit)
- `src/apps/maps/youbike/` — station parse, nearest-station pick, YouBike trip planner, OSRM bike-route client
- `GET /api/youbike/stations` — cached YouBike 2.0 proxy (official national dump)
- `GET /api/youbike/route` — cached no-key OSRM bike geometry fallback when MapKit Cycling is unavailable

### Chats UI

- `src/components/shared/MapsSearchPlacesCard.tsx` — Inline tool results; row opens Maps in-app; external icon opens `appleMapsUrl`
