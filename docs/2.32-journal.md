# Journal

Journal is a local demo of two ways to keep the same days. One is the complete journal a tool might hand back: a date, a mood score, a streak, a daily reminder, and a weekly report, with one page per day. The other is a freeform notebook: text and photos scattered on a page, including scraps from different days. Nothing in the demo is generated live, and the sample does not need a server.

Open it from Applications, or visit `/journal`.

## Views

The toolbar switches among three views. File ▸ Reset Demo, or the toolbar Reset Demo button, puts the sample back.

- **Complete Answer.** Every feature starts on. Each one has its own switch, so a single feature can be removed. The streak is marked as the default one to remove.
- **Counter and Workbench.** The same request sits on both sides, labeled as an illustration rather than a speed comparison. The service window returns one finished version and only offers accept all, reject all, or ask again. The workbench lists the planned edits — remove the streak, turn off the reminder, switch to freeform scraps — and each edit can be kept or applied on its own. It shows a before and after, can drop in a sample photo, and can undo or revert the plan. Accepting the service window does not change the workbench.
- **Two Structures.** The same sample days render as one page per day and as freeform scraps, side by side on a wide window and stacked on a narrow one. Feature switches still apply to the daily pages. The freeform page does not show scores, streaks, or the reminder.

Drag a scrap to move it. The position is saved on this device with the rest of the demo state.
